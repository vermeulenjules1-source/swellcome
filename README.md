# Swellcome

Prévisions surf pour toute la France, adaptées au niveau de chaque surfeur. Ne plus rater aucune session.

Projet en construction : prototype sur dix spots de Gironde. Le contexte complet est dans `docs/contexte.md` et les choix de données et de licences dans `docs/donnees-spots-licences.md`.

Données de prévision : [Open-Meteo](https://open-meteo.com/) (CC BY 4.0). Marées calculées à partir de FES2022 (CNES/AVISO), à titre indicatif.
